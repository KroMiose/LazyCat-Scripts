# codex-hud 0.1.0

首个独立程序版本，支持 macOS/Linux 的 ARM64、AMD64。

- Bark 审批通知、每轮结束通知与四种主动通知，按显示宽度截断。
- Key 隐藏配置、短规则接入、精确同轮去重、暂停和卸载。
- 固定版本安装器、全链路显式镜像、程序和托管集成的失败回滚。
- 安装记录格式 1，兼容首次开发版无版本记录；不兼容的未来格式会拒绝修改。

用户无需 Go、Python 或 Node。安装后通过 `setup` 配置 Key，并在 Codex 客户端审核 Hooks；文件完整不代表 Hooks 已加载或设备收到通知。用 `config test` 验证手机/眼镜。

下载项包含四个平台程序、固定版本 `install.sh`、`LICENSES.txt` 和覆盖全部文件的 `SHA256SUMS`。已发布版本不替换资产；修复使用新标签。
